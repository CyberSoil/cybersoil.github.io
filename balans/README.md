# Баланс — персональный дневник веса и питания

**Бесплатное PWA, без подписки, рекламы и сторонних API.** Интерфейс на русском языке. Создано как собственная реализация по пользовательскому описанию, не является копией чужого кода.

## Что работает

- Начальные значения: **67 кг → 55 кг** (можно менять).
- Редактируемый профиль: рост, возраст, параметр формулы, активность, желаемый темп, цели воды и шагов.
- Оценка обмена энергии по Mifflin–St Jeor, консервативный лимит дефицита (не более ~20% от расчётного расхода) и пересчёт макронутриентов.
- Дневник еды: блюда, калории, белки, жиры, углеводы, клетчатка; удаление записей. Есть небольшой встроенный справочник из 25 обычных продуктов с приблизительными значениями на 100 г: можно выбрать продукт, указать массу и подставить нутриенты, затем проверить цифры вручную.
- Вода, шаги, минуты тренировок, ежедневные заметки.
- Взвешивания, история и график прогресса. Ориентировочная дата достижения цели, без гарантий.
- Автоматические **правила-подсказки**, не генеративный ИИ и не врач: по достаточности заполнения дневника, калориям, белку, клетчатке, воде, скорости изменения веса.
- «Скопировать сводку для GPT» — переносит последние записи текстом в буфер обмена, чтобы обсудить их в ChatGPT **вручную**. Внутри PWA нет ChatGPT API (он потребовал бы подключение, расходы и отдельную работу с приватностью).
- Резервная копия JSON, импорт JSON, экспорт CSV, удаление данных.
- Всё хранится **только в localStorage того браузера**, в котором открыто приложение; никуда не отправляется.
- После первой загрузки по HTTPS приложение доступно офлайн благодаря Service Worker.

## Как пользоваться

### Быстрый локальный просмотр

Откройте `index.html` на компьютере. Обычные функции работают, но полная офлайн-установка требует HTTPS (или `localhost`).

Для локального тестирования с компьютера:

```bash
cd balans-pwa
python3 -m http.server 8000
```

Откройте http://localhost:8000. На iPhone `localhost` относится к самому телефону, поэтому для установки на iPhone удобнее разместить сайт через HTTPS.

### Бесплатная публикация и установка на iPhone

Пример с **GitHub Pages** (для публичного репозитория на бесплатном тарифе):

1. Создайте публичный репозиторий в GitHub, например `balans`.
2. Загрузите в корень репозитория все файлы из этой папки вместе с папкой `icons`.
3. В Settings → Pages выберите **Deploy from a branch**, `main`, `/ (root)` и сохраните.
4. Откройте полученный HTTPS-адрес `https://<ваш-логин>.github.io/balans/` в **Safari на iPhone**.
5. В меню Safari нажмите **Поделиться → На экран «Домой» → Добавить**.
6. После первого открытия приложение может работать без интернета. Дневник хранится на телефоне, а не в публичном репозитории.

Важно: исходный код будет открытым для всех, но ваши локальные записи не публикуются. Не загружайте файл резервной копии JSON в публичный GitHub-репозиторий.

Можно вместо GitHub Pages воспользоваться любым бесплатным HTTPS-хостингом статических сайтов, где PWA/service worker разрешены.

## Приватность

- Не содержит рекламных скриптов, аналитики, трекеров и API.
- Информация хранится в памяти Safari/браузера. Если очистить данные сайтов, удалить PWA или сменить телефон, данные могут исчезнуть.
- Для сохранения истории регулярно нажимайте **Мой план → Резервная копия JSON** и сохраняйте файл в «Файлы»/iCloud Drive.
- При открытии из разных браузеров записи не синхронизируются. Импорт JSON позволяет переносить их вручную.

## Важные ограничения

- Это **дневник привычек**, не медицинская программа и не рекомендация реального диетолога в чате.
- Программа не назначает дефицит при возрасте до 18 лет или при ИМТ ниже 18,5 (исходном или целевом). При беременности, лактации, заболеваниях, лечении препаратами и расстройствах пищевого поведения требуется индивидуальный медицинский подход.
- Изменение веса не линейно. Ориентир по срокам не обещает конкретной даты.
- Калории не добавляются второй раз за тренировку, поскольку выбранный коэффициент активности уже учитывает привычную нагрузку.
- Калькулятор использует общие оценки и пороги, которые могут быть неприменимы лично вам.
